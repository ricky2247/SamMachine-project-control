PROJECT CONTROL CENTER - V5

WHAT CHANGED
------------
1. Project cards are selected ONLY by click.
2. Hover only changes the card's visual emphasis; it does not select or move it.
3. The project carousel is responsive for desktop/tablet/mobile.
4. Comments panel added on the left on desktop and below the content on mobile.
5. Comments can be shared between the three users through Supabase.
6. If Supabase is not configured, comments temporarily use browser localStorage on that device.

SHARED COMMENTS SETUP (RECOMMENDED)
------------------------------------
Supabase is used because the website is static and the comments need to remain visible to all 3 users.

A) Create a free Supabase project.
B) In Supabase -> SQL Editor, run:

create table public.project_comments (
  id bigint generated by default as identity primary key,
  author text not null check (char_length(author) between 1 and 40),
  message text not null check (char_length(message) between 1 and 500),
  created_at timestamptz not null default now()
);

alter table public.project_comments enable row level security;

create policy "public can read comments"
on public.project_comments
for select
using (true);

create policy "public can add comments"
on public.project_comments
for insert
with check (
  char_length(author) between 1 and 40
  and char_length(message) between 1 and 500
);

C) In Supabase -> Project Settings -> API, copy:
   - Project URL
   - anon/public key

D) Open supabase-config.js and replace:
   YOUR_SUPABASE_URL
   YOUR_SUPABASE_ANON_KEY

Do NOT use the service_role/secret key in the website.

RUNNING THE WEBSITE
--------------------
Open index.html in a browser for a quick local preview.
For the shared Supabase comments, deploy the whole folder to a static host such as Cloudflare Pages or GitHub Pages.

IMPORTANT
---------
The three users do not need Supabase accounts with this simple setup. They enter a display name when posting a comment.
Because there is no login, anyone who can access the public site can technically post comments. For a private internal system, add authentication later.
